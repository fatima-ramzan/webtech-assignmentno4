# Markdown Slides Presentation

A simple web application to create, edit, save, and present slides using Markdown with a live preview.

## Features
- Create and edit slides.
- Live slide preview.
- Save slides in browser storage.
- Navigate slides using buttons and arrow keys.
- Fullscreen presentation mode.
- Slide counter and keyboard shortcuts.

## Technologies
HTML, CSS, JavaScript, and Marked.js.

## How to Run
1. Open the project in VS Code.
2. Run `index.html` using Live Server.
3. Create slides using Markdown and separate them with `---`.

## Storage
Slides are saved in browser `localStorage`.
