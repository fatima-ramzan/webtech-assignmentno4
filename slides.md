# Introduction

Welcome to my Markdown Slides Application.

This application helps users create and present slides easily.

# Features

- Create and edit slides
- Live slide preview
- Save slides in browser memory
- Export Markdown file
- Fullscreen presentation mode
- Keyboard shortcuts

---

# Technologies Used

- HTML
- CSS
- JavaScript
- Markdown
- Marked.js

---

# How It Works

Write your content in Markdown.

Use three dashes (---) to create a new slide.

Preview and present your slides easily.
